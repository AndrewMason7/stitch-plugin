# Design-to-Code Conversion Runbook

When taking raw HTML/Tailwind screens generated by Stitch and turning them into production React, Vite, and Tailwind components, follow this protocol.

---

## 1. Remediation Checklist

Stitch outputs self-contained HTML that requires transformation before production use:

| Artifact in Stitch Output | Production Requirement | Action Required |
| :--- | :--- | :--- |
| `href="#"` | Real React Router `<Link to="...">` | Replace every single dead link |
| Monolithic single-file HTML | Modular atomic components | Extract Header, Sidebar, Card, Table |
| `md:hidden` bottom navbars | Responsive desktop navigation | Add desktop top nav + clickable logo |
| Hardcoded sample data | Dynamic state props / queries | Connect TanStack Query or mock hooks |
| Plain `<div>` buttons | Interactive `<button>` or Radix primitives | Add `aria-label`, `:focus-visible`, keyboard tab |

---

## 2. Component Decomposition Pipeline

```text
Stitch Screen HTML
   │
   ├── [TopAppBar.tsx]           <-- Logo link, search trigger, profile menu
   ├── [SidebarNavigation.tsx]   <-- Desktop vertical navigation
   ├── [StatMetricsGrid.tsx]     <-- KPI indicator cards with sparklines
   ├── [ActivityTable.tsx]       <-- Data table with sorting/filtering
   └── [BottomNavbar.tsx]        <-- Mobile bottom tabs (hidden on md+)
```

---

## 3. Responsive Navigation Standard

Stitch designs often hide bottom bars on desktop using Tailwind's `md:hidden`. Without a corresponding desktop navbar, desktop users cannot navigate!

Always implement the **Universal Navigation Pattern**:
```tsx
// Header.tsx
export function Header() {
  return (
    <header className="sticky top-0 z-50 flex items-center justify-between border-b border-border/40 bg-background/80 backdrop-blur-md px-6 py-3">
      {/* Brand logo MUST link to root */}
      <Link to="/" className="flex items-center gap-2 font-semibold">
        <LogoIcon className="h-6 w-6 text-primary" />
        <span>Brand</span>
      </Link>

      {/* Desktop Links (visible on md+) */}
      <nav className="hidden md:flex items-center gap-6 text-sm font-medium">
        <Link to="/dashboard" className="text-muted-foreground hover:text-foreground">Dashboard</Link>
        <Link to="/analytics" className="text-muted-foreground hover:text-foreground">Analytics</Link>
        <Link to="/settings" className="text-muted-foreground hover:text-foreground">Settings</Link>
      </nav>

      {/* Action CTA */}
      <Button variant="default" size="sm">Connect Wallet</Button>
    </header>
  );
}
```
